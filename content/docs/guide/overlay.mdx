<Lead>
The overlay is a diagnostics panel. It can show the engine mode and poll rate, input counters and dispatch/queue measurements. By default it appears only while the F3 debug screen is open.
</Lead>

## Visibility

The overlay requires <code>show_f3_info=true</code>, a player and a visible HUD (F1 must not be hiding it). It is suppressed when opacity is at or below 0.001 unless the test rectangle is enabled. It is drawn when <code>overlay_mode=1</code> or the F3 debug screen is open; the default mode is F3-only.

When F3 is open, the panel is placed below the debug text and its background is hidden so it does not cover the debug display.

## What it shows

| Line | Setting | Content |
| --- | --- | --- |
| Title | Always | InputBooster version |
| Engine | <code>overlay_show_engine</code> | Engine mode and current poll rate |
| Counters | <code>overlay_show_events</code> | Keyboard, mouse and submitted-action counters |
| Dispatch | <code>overlay_show_overhead</code> | Mean dispatch time and queue depth |
| Experimental warning | When custom keyboard handler is enabled | Indicates the experimental handler |

The panel is rebuilt at most four times per second and reuses its line storage. Its dispatch measurement is not end-to-end input latency or a vanilla comparison.

## Position

<code>overlay_position</code> supports five values:

| Value | Position |
| --- | --- |
| 0 | Top-left (default) |
| 1 | Top-right |
| 2 | Bottom-left |
| 3 | Bottom-right |
| 4 | Top-center |

The layout clamps the panel to the screen after resizing. If the panel is larger than the available area, its coordinate is pinned to zero rather than becoming negative.

## Appearance

| Setting | Range | Default |
| --- | --- | --- |
| <code>overlay_scale</code> | 0.5–3.0 | 1.0 |
| <code>overlay_opacity</code> | 0.0–1.0 | 0.8 |
| <code>overlay_color</code> | ARGB integer | <code>0xFFE6EDF3</code> |
| <code>overlay_test_rect</code> | Boolean | false |

The UI colour selector offers White, Cyan, Green, Yellow, Orange, Red, Magenta and Grey. A hand-edited ARGB value remains in the properties file; the UI displays the closest preset until a new colour is selected. The properties parser expects a signed decimal integer (for the default white, <code>-1643021</code>); a <code>0x</code> prefix is not accepted.

The test rectangle is a bright diagnostic shape used to verify where the overlay is drawn. It is not part of normal gameplay display.

## Keystroke display

<code>show_keystrokes</code> is still stored and exposed in the UI, but the current renderer has no keystroke-display implementation. Changing it does not draw key states.

## Client command

The client command reports status and can control the overlay:

~~~text
/inputbooster
/inputbooster overlay on
/inputbooster overlay off
/inputbooster overlay test
/inputbooster overlay position top-left
/inputbooster overlay position top-right
/inputbooster overlay position top-center
/inputbooster overlay position bottom-left
/inputbooster overlay position bottom-right
~~~

<code>overlay test</code> toggles the test rectangle. <code>overlay on</code> and <code>overlay off</code> change the overlay master switch. Position changes are saved to the configuration.
