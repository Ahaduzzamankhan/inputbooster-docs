<Lead>
The profile manager still stores snapshots of 23 settings, up to five profiles. The current settings screens do not expose profile management controls, so players who use profiles must edit the JSON and server-binding files manually.
</Lead>

## Current UI limitation

There is no in-game Save, Load or Delete profile screen in the current 4.1.2 UI, and there is no client command for those operations. <code>ProfileManager</code> retains the internal capture/apply/save/delete methods, while <code>PerServerProfileManager</code> can load a profile bound to the current server.

To use per-server profiles, create the profile JSON and binding properties file while Minecraft is closed. The format is documented in [Profile format](/docs/configuration/profiles-format).

## What a profile captures

A profile contains 23 fields:

| Group | Fields |
| --- | --- |
| Polling | <code>pollRateHz</code>, <code>pollRateAutoMode</code> |
| Movement | <code>sprintFixEnabled</code>, <code>autoSprintEnabled</code>, <code>wTapAssistEnabled</code>, <code>antiIdleEnabled</code>, <code>autoStrafeEnabled</code> |
| Combat | <code>cpsLimiterEnabled</code>, <code>maxCps</code>, <code>cpsMode</code> |
| Overlay | <code>showF3Info</code>, <code>showKeystrokes</code>, <code>showActionBar</code> |
| Diagnostics | <code>fpsCheckInterval</code>, <code>debugMode</code> |
| Engine/features | <code>burstModeEnabled</code>, <code>comboKeysEnabled</code>, <code>replayEnabled</code>, <code>safeModeEnabled</code>, <code>eventLogEnabled</code>, <code>keyConflictWarn</code>, <code>perServerProfiles</code> |

## Limits

- Maximum profiles: five.
- A profile name is matched case-insensitively.
- Missing or wrongly typed JSON fields use their defaults.
- Invalid JSON is moved aside to <code>inputbooster_profiles.json.corrupt</code>; the client continues with no loaded profiles.

## Files

<code>.minecraft/config/inputbooster_profiles.json</code> stores the profile array.

<code>.minecraft/config/inputbooster_server_profiles.properties</code> maps a normalised server identifier to a profile name:

~~~properties
example.com=Competitive
hypixel.net=Slow
singleplayer=Casual
~~~

Server detection runs every 20 ticks. Identifiers are normalised to lower case, without a scheme, path or default port 25565.

## Settings not captured

Overlay placement, scale, opacity, colour and test rectangle; engine mode; custom keyboard handler; compatibility fallback; keyboard repeat guard; mouse debounce and click deduplication; click sound settings; and config schema version are outside the profile record. Applying a profile leaves those values unchanged.
