<Lead>
The archived API project and the current InputBooster mod are separate deliverables. Current 1.21.x mod jars exist, but they do not restore or bundle the archived public API.
</Lead>

## Separate projects

| | Archived API | Current mod artifacts |
| --- | --- | --- |
| Minecraft | 1.21.x | 1.21.1, 1.21.4, 1.21.11, 26.1, 26.1.2, 26.2, 26.3 |
| Loader | Fabric | Fabric only |
| Java | 21 | 21 for 1.21.x; 25 for 26.x |
| Mod/API version | API 3.1.0 | Mod 3.1.5 on 1.21.x; 4.1.2 on 26.x |
| Status | Archived and unmaintained | Mod artifacts are built by the current release workflow |

There is no bridge between the API and the mod. The current mod source does not contain the old <code>dev.inputbooster.api</code> package or register the old API entrypoint.

## What this means

- A mod compiled against the archived API cannot assume the current InputBooster jars provide those API classes.
- Installing a current 1.21.x InputBooster jar does not make the archived API available.
- The 1.21.x mod builds are separate older project trees, not the 4.1.2 26.x project compiled against a different Minecraft version.
