| Target | Minecraft range | Java range |

The 1.21.x projects are separate older codebases. They are not the 4.1.2 26.x implementation compiled against a different game version.

## Optional integrations

- **Mod Menu** is optional and provides a configuration entry.
- **Sodium** is optional. The 26.x projects declare the Sodium Config API entrypoint and expose native Sodium settings pages when a compatible Sodium build is installed.
- The 1.21.x projects do not declare the Sodium Config API entrypoint. Use the vanilla options screen or Mod Menu for those builds, even if Sodium is installed.

## What is not supported

| Combination | Status |
| --- | --- |
| NeoForge | No current build |
| Minecraft 26.0 or 26.4+ | No matching jar |
| Minecraft 1.21.2–1.21.10 | No matching jar |
| Java 21 with Minecraft 26.x | Unsupported; use Java 25 |
| Java 25 with Minecraft 1.21.x | Not required; Java 21 is the declared minimum |
| Server-side installation | Unsupported; the mod is client only |

<Callout variant="info" title="Why version ranges use comparisons">
The Fabric metadata uses the space-separated comparison form, such as <code>>=26.3 &lt;26.4</code>. Keep that form when editing metadata; the project has a regression test for it.
</Callout>
