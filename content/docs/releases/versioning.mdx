<Lead>
Do not treat the mod version, release tag, Minecraft version and config schema as the same number. The current release tag is <code>v4.1.2-beta3</code>; its 1.21.x artifacts retain mod version 3.1.5.
</Lead>

## The version fields

| Field | Current value | Meaning |
| --- | --- | --- |
| Release tag | <code>v4.1.2-beta3</code> | GitHub release identifier; marked as a prerelease |
| Mod version on 26.x | <code>4.1.2</code> | Embedded in the 26.x jars and startup line |
| Mod version on 1.21.x | <code>3.1.5</code> | Embedded in the separate legacy 1.21.x jars |
| Config schema | <code>306</code> | Value written to <code>config_version</code> by all seven current builds |
| Minecraft target | Per artifact | Encoded in the jar suffix and Fabric metadata |

## Current jar naming

~~~text
inputbooster-<mod-version>-mc<minecraft-without-dots>.jar
~~~

Examples:

| Minecraft | Mod version | Jar |
| --- | --- | --- |
| 26.3 | 4.1.2 | <code>inputbooster-4.1.2-mc263.jar</code> |
| 26.2 | 4.1.2 | <code>inputbooster-4.1.2-mc262.jar</code> |
| 26.1.2 | 4.1.2 | <code>inputbooster-4.1.2-mc2612.jar</code> |
| 26.1 | 4.1.2 | <code>inputbooster-4.1.2-mc261.jar</code> |
| 1.21.11 | 3.1.5 | <code>inputbooster-3.1.5-mc12111.jar</code> |
| 1.21.4 | 3.1.5 | <code>inputbooster-3.1.5-mc1214.jar</code> |
| 1.21.1 | 3.1.5 | <code>inputbooster-3.1.5-mc1211.jar</code> |

The loader flavour is no longer part of the filename because the current release is Fabric-only.

## Config schema

The current properties schema is <code>306</code> in both project lines. It is independent of the mod version: 4.1.2 for 26.x and 3.1.5 for 1.21.x both write <code>config_version=306</code>.

~~~properties
config_version=306
~~~

Older 3.x config files are migrated on load by renaming the supported legacy keys. Unknown keys are ignored; invalid values are reset to their defaults and reported in the log.

## Release pipeline

The source workflow reads the release tag from the main <code>fabric/gradle.properties</code> project, builds the seven target artifacts, verifies the output set and publishes the release. The 1.21.x artifacts keep their own 3.1.5 mod metadata even though they are attached to the same release asset set.

## Stability labels

- <strong>Beta:</strong> the current 4.1.2 build is published under a beta tag and is not the last stable line.
- <strong>Last stable release:</strong> 4.0.3-stable.
- Historical alpha and withdrawn releases remain listed in the [changelog](/docs/releases/changelog).
