## Release and test coverage

The current release tag is <code>v4.1.2-beta3</code>. The 26.x artifacts report 4.1.2; the 1.21.x artifacts report 3.1.5 and are separate older project trees. The last stable release remains 4.0.3-stable.

The project does not publish a client FPS or end-to-end latency benchmark. The internal profiler measures time from action capture to game-thread drain; that is not hardware input latency and is not a comparison against vanilla.

<Callout variant="warning" title="The current CI does not launch Minecraft">
The latest Build and Release workflow passed its seven build/test targets, but the current source branch contains only <code>.github/workflows/gradle.yml</code>; it has no headless client startup job. The last recorded smoke run (14 November 2026, commit <code>973e0f1</code>) failed in 11 of 12 mod combinations. The 26.3/Iris job failed during graphics initialization with <code>Couldn't find matching GLX visual</code>; the 26.2/no-Sodium job also logged a GLFW invalid-key callback from the poller thread. A user-properties HTTP 401 was incidental, not the fatal cause. No later smoke run verifies that the graphics issue is fixed.
</Callout>

## Persisted settings without runtime effect

These five settings are stored and exposed in the UI, but current runtime code does not use them:

| Key | Expected effect | Current behavior |
| --- | --- | --- |
| <code>show_keystrokes</code> | Draw a keystroke panel | No keystroke renderer exists |
| <code>fps_check_interval</code> | Set the adaptive FPS sampling interval | The adaptive rate is recomputed every client tick |
| <code>keyboard_repeat_guard</code> | Toggle repeat filtering | GLFW repeat events are discarded unconditionally |
| <code>debug_mode</code> | Enable verbose diagnostics | No logging is gated on this value |
| <code>click_sound_volume</code> | Change click sound loudness | The sound manager passes pitch but not volume to the sound instance |

## Features without a player-facing interface

| Feature | Current state |
| --- | --- |
| Event log | Bounded in-memory collection; no viewer screen |
| Config import/export and presets | Implemented in ConfigTools, but no current UI or command calls those methods |
| Profile management | ProfileManager retains internal save/load/delete methods, but the current settings screens expose no profile manager |
| Per-server profile bindings | The manager can load a bound profile; there is no binding UI or command, so the JSON and properties files must be edited manually |

## Behavior narrower than the setting name suggests

| Setting or feature | Actual behavior |
| --- | --- |
| <code>show_action_bar</code> | Gates burst-mode start/end messages, not every message sent by the mod |
| <code>cps_mode</code> | Unknown or null values are sanitized to <code>FIXED</code> |
| <code>mouse_scroll_debounce_ms</code> | Debounces/counts scroll events; the mod does not apply scrolling to the game |
| <code>overlay</code> | Shows engine/counter/dispatch diagnostics; it is not a keystroke display or an end-to-end latency meter |

## Action boundaries

- **Attack:** only a living entity within vanilla melee reach is attacked: three blocks, squared distance 9.
- **Use:** the mod executes use only when the crosshair result is a miss. Blocks and entities return to vanilla handling.
- **Block breaking:** remains a vanilla held-key mechanic.
- **Offhand swap:** remains vanilla's responsibility.
- **Pick block:** requires the pick-block accessor hook to have applied.

## Compatibility detection

Automatic fallback checks four Fabric mod IDs: Controlify, Midnight Controls, Controllable and Zoomify. Detection uses Fabric Loader's mod list. Sodium and Iris are rendering mods and are not treated as input-owning mods.

The experimental custom keyboard handler remains off by default. It is not a substitute for checking the screen-tracking hook or removing a conflicting input mod.

## Supported versions

The current release workflow builds seven Fabric client artifacts:

| Minecraft | Mod version | Java |
| --- | --- | --- |
| 26.3, 26.2, 26.1.2, 26.1 | 4.1.2 | 25 |
| 1.21.11, 1.21.4, 1.21.1 | 3.1.5 | 21+ |

Fabric Loader 0.19.0 or newer is declared for these builds. Use the matching Fabric API version in the [support matrix](/docs/releases/support-matrix). There is no current NeoForge or server-side build.

The root source README still summarizes only Minecraft 26.2/26.3 and mentions a profile-management UI. The release workflow builds seven targets, and the current settings screen has no profile-management controls. The documentation follows the module metadata and workflow; those README statements remain upstream discrepancies.

## The archived API

The old public API project is archived and is not bundled into any current mod artifact. The 1.21.x mod jars do not restore the API package or its entrypoint.
