<Lead>
Every current artifact is a Fabric client mod. A server does not install InputBooster and does not need a companion plugin.
</Lead>

## Where it runs

The Fabric metadata marks the mod environment as client-only and registers a client entrypoint. There is no server entrypoint, server mixin or custom network packet.

## What the server receives

InputBooster calls vanilla client methods. It does not send packets of its own.

| Action | Client call | Server receives |
| --- | --- | --- |
| Attack entity | <code>gameMode.attack(player, target)</code> | The normal vanilla attack packet |
| Use item | <code>gameMode.useItem(player, InteractionHand.MAIN_HAND)</code> | The normal vanilla use packet |
| Jump | <code>player.jumpFromGround()</code> | Normal movement state |
| Sprint | <code>player.setSprinting(true)</code> | Normal movement state |

The server receives ordinary client actions. InputBooster does not bypass server-side reach, cooldown or anticheat validation.

## What it does not do

- It does not extend reach. The drainer rechecks that the target is alive and within vanilla melee reach: three blocks, or squared distance 9.
- It does not change hit registration or attack cooldown.
- It does not generate input without a physical key or button edge.
- It does not replace vanilla keyboard or mouse handlers.
- It does not provide auto-attack, auto-mine or aim assist.
- It does not provide a NeoForge build.

<Callout variant="note" title="Server rules still apply">
Individual multiplayer servers and anticheat systems set their own rules for modified clients. InputBooster does not claim that every server permits it.
</Callout>
