## Jars that must not be used

<Callout variant="danger" title="4.0.2-stable crashes on launch">
`4.0.2-stable` crashes before the main menu on every client. The three
accessor mixins carried their cast helpers as `public static` methods, which
Mixin rejects, and that aborts the transformation of `Minecraft` itself. Use
`4.0.3-stable` instead.
</Callout>

| Version | Why it is unusable |
| --- | --- |
| `4.0.2-stable` | Crashes before the main menu on every client. Use 4.0.3-stable. |
| `4.1.0-alpha` | Crashes during startup on every loader: the keyboard mixin was written against the 1.21 signature and 26.x uses `keyPress(long, int, KeyEvent)`. |
| `3.1.2` | Every Fabric jar rejects the Minecraft version it was built for. The dependency range `[26.2,26.3)` is parsed incorrectly by Fabric Loader 0.19.5. |
| `3.1.3` | Crashes on startup. Three accessors were declared as interface mixins against class targets. |

The full list of what changed in each release is in the
[changelog](/docs/releases/changelog).

## Naming scheme

The suffix tells you everything:

```text
inputbooster-<version>-<loader>-mc<minecraft>.jar
                │          │       └─ 262 or 263
                │          └───────── fabric or nf
                └──────────────────── 4.1.2-alpha
```

`nf` is NeoForge. There is no `nf-mc263` jar because the NeoForge build
targets Minecraft 26.2 only.

## Picking a file in five seconds

1. Do you play on NeoForge? If yes, take `nf-mc262` and you must be on
   Minecraft 26.2.
2. Otherwise take a `fabric` jar.
3. Match `mc262` or `mc263` to your Minecraft version.
4. Take the highest version number in that row.
