## Why two mod versions appear

The four 26.x artifacts report mod version 4.1.2. The three 1.21.x artifacts report 3.1.5 and come from independent legacy project directories. They are separate builds, not interchangeable jars.

All seven are Fabric client mods. There is no NeoForge artifact in the current release workflow.

## Select and install

<Steps>
  <Step title="Check the exact Minecraft version">
    Do not choose a jar based on a nearby version. For example, 26.1 and 26.1.2 have different artifacts.
  </Step>
  <Step title="Check Java">
    Use Java 25 for Minecraft 26.x and Java 21 or newer for the 1.21.x builds.
  </Step>
  <Step title="Install Fabric">
    Install a Fabric Loader version of 0.19.0 or newer and the Fabric API version listed in the [support matrix](/docs/releases/support-matrix).
  </Step>
  <Step title="Copy one jar">
    Put exactly one matching InputBooster jar in the instance's <code>mods</code> folder.
  </Step>
</Steps>

<Callout variant="danger" title="Do not combine jars">
Each artifact contains the mod's client entrypoints and mixins. Two versions in one <code>mods</code> folder can load duplicate classes and cause startup failure.
</Callout>
