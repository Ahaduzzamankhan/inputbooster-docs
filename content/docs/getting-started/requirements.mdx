<Lead>
InputBooster 4.1.2-alpha needs Java 25, a Fabric or NeoForge client, and Minecraft
26.2 or 26.3. There is no build for any other Minecraft version in this source
tree.
</Lead>

## The short version

| Requirement | Value |
| --- | --- |
| Java | 25 |
| Minecraft | 26.2 (Fabric, NeoForge) or 26.3 (Fabric only) |
| Loader | Fabric Loader 0.19.0+ and Fabric API 0.161.0+, or NeoForge 26.2.0.88+ |
| Side | Client only |
| Mod loader install | Exactly one InputBooster jar |

## Java 25

The mixin manifest declares `compatibilityLevel: JAVA_25`, and the Fabric
`fabric.mod.json` requires `"java": ">=25"`. A Java 21 runtime cannot load the
mod.

<Callout variant="warning" title="Check your Java, not just the launcher">
A launcher can be configured for one Java version and still launch the game with
another. If the game refuses to start with a class-version error, the launcher
is the thing to check, not the mod.
</Callout>

To confirm which Java a launcher uses, look at the launcher's version or
profile panel, or run a command in the folder that contains the launcher:

<Command command="java -version" block label="Verify your default Java" />

## Minecraft versions

Only two Minecraft versions are built from this tree:

| Minecraft | Fabric jar | NeoForge jar |
| --- | --- | --- |
| 26.2 | `inputbooster-4.1.2-alpha-fabric-mc262.jar` | `inputbooster-4.1.2-alpha-nf-mc262.jar` |
| 26.3 | `inputbooster-4.1.2-alpha-fabric-mc263.jar` | — |

There is no NeoForge build for 26.3. The NeoForge build targets Minecraft 26.2
through the `neoforge.mods.toml` dependency range `[26.2,26.3)`.

<Callout variant="danger" title="1.21.x is not supported here">
Older versions of this mod existed for Minecraft 1.21.x. That line is not part
of this source tree, and the [archived API](/docs/releases/archived-api) does
not make 1.21 work. If you need 1.21, you need a different build from the
project's release history.
</Callout>

## Fabric requirements

The Fabric build declares these dependencies:

```json
"depends": {
  "fabricloader": ">=0.19.0",
  "fabric-api": ">=0.161.0",
  "minecraft": ">=26.3 <26.4",
  "java": ">=25"
}
```

The 26.2 jar replaces the Minecraft range with `>=26.2 <26.3`.

Fabric API is a hard dependency. The mod does not ship a Fabric API
implementation, and the platform entrypoint registers key mappings through the
loader API.

<Callout variant="info" title="Why the range has no brackets">
The 26.3 jar uses `>=26.3 <26.4` rather than `[26.3,26.4)`. Fabric Loader
0.19.5 mis-parses bracket ranges when the Minecraft version has two components
and rejects 26.3 itself. The space-separated comparison form is parsed
correctly. This is a loader bug workaround, not a version policy.
</Callout>

## NeoForge requirements

The NeoForge build requires `neoforge` `[26.2.0.88,)` and `minecraft`
`[26.2,26.3)`. NeoForge bundles the loader, so there is no separate Fabric API
requirement. The mod is declared `side="CLIENT"`.

## Checking what you have

Before installing, confirm three things:

1. The Minecraft version in your launcher matches the jar's `mc262` or `mc263`
   suffix.
2. Your loader version is new enough for the table above.
3. Your Java is 25.

The [jar matrix](/docs/installation/jar-matrix) page maps every published jar to
its version range, and [installing](/docs/getting-started/installation) covers
the actual file placement.

## What you do not need

- **A server-side install.** The mod is client only. A server does not install
  it, does not need a plugin for it, and cannot see it.
- **Fabric API on NeoForge.** Not applicable.
- **A separate API mod.** The public API repository is archived and is not
  wired into 26.x. See [archived API](/docs/releases/archived-api).
