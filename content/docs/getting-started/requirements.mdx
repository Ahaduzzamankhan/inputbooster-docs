<Lead>
InputBooster is Fabric-only and client-side. Java depends on the Minecraft line: Java 25 for 26.x, Java 21 or newer for 1.21.x.
</Lead>

## Required components

| Component | Requirement |
| --- | --- |
| Loader | Fabric Loader 0.19.0 or newer |
| API | The Fabric API build matching your Minecraft target; see the table below |
| Java for Minecraft 26.x | Java 25 |
| Java for Minecraft 1.21.x | Java 21 or newer |
| Installation side | Client only |
| NeoForge | Not supported by the current source tree |

## Match Fabric API to Minecraft

| Minecraft | Configured Fabric API |
| --- | --- |
| 26.3 | 0.161.0+26.3 |
| 26.2 | 0.161.0+26.2 |
| 26.1.2 | 0.155.3+26.1.2 |
| 26.1 | 0.155.3+26.1.2 |
| 1.21.11 | 0.141.6+1.21.11 |
| 1.21.4 | 0.119.4+1.21.4 |
| 1.21.1 | 0.116.18+1.21.1 |

Use the API release matching the exact game version. The metadata declares the corresponding minimum API version.

## Optional mods

- **Sodium:** optional. On the 26.x builds, a compatible Sodium Config API exposes InputBooster's native pages in Sodium Video Settings. The 1.21.x builds do not declare that entrypoint.
- **Mod Menu:** optional. Its configuration entry opens the vanilla settings screen.

Neither optional mod is required for the input engine to run.

## Client only

InputBooster has no server jar, server entrypoint or companion plugin. Only the player using the mod installs it. A multiplayer server does not need InputBooster.

## Check Java

Run the following in a terminal:

~~~bash
java -version
~~~

For a 26.x instance, the runtime must be Java 25. For a 1.21.x instance, Java 21 is the declared minimum.
