## Before you start

1. Install Fabric Loader 0.19.0 or newer for your Minecraft version.
2. Install the matching Fabric API release.
3. Select the correct Java runtime: Java 25 for Minecraft 26.x, Java 21 or newer for 1.21.x.
4. Download one InputBooster artifact from the [GitHub releases page](https://github.com/Ahaduzzamankhan/inputbooster/releases).

Use the [support matrix](/docs/releases/support-matrix) to confirm the exact API version.

## Choose the jar

| Minecraft | Jar |
| --- | --- |
| 26.3 | <code>inputbooster-4.1.2-mc263.jar</code> |
| 26.2 | <code>inputbooster-4.1.2-mc262.jar</code> |
| 26.1.2 | <code>inputbooster-4.1.2-mc2612.jar</code> |
| 26.1 | <code>inputbooster-4.1.2-mc261.jar</code> |
| 1.21.11 | <code>inputbooster-3.1.5-mc12111.jar</code> |
| 1.21.4 | <code>inputbooster-3.1.5-mc1214.jar</code> |
| 1.21.1 | <code>inputbooster-3.1.5-mc1211.jar</code> |

The 1.21.x artifacts are separate 3.1.5 builds. Do not substitute a 26.x jar or a jar for a different 1.21 patch release.

## Install the jar

<Steps>
  <Step title="Open the instance folder">
    Open the Minecraft instance's game directory, then open its <code>mods</code> folder. Create the folder if it does not exist.
  </Step>
  <Step title="Copy the matching artifact">
    Copy exactly one InputBooster jar into <code>mods</code>. Do not keep another InputBooster version beside it.
  </Step>
  <Step title="Launch the Fabric profile">
    Start Minecraft using the Fabric installation and the Java version required by that game line.
  </Step>
  <Step title="Open settings">
    Open Options and select the InputBooster button. Mod Menu can also open the vanilla settings screen. On 26.x, a compatible Sodium Config API additionally exposes InputBooster pages in Sodium Video Settings.
  </Step>
</Steps>

## Optional integrations

Sodium and Mod Menu are optional. The 26.x builds register Sodium configuration pages when a compatible Sodium Config API is available. The 1.21.x builds do not register that API entrypoint, so use the vanilla options screen or Mod Menu for those versions.

## Verify the installation

The client log should contain an InputBooster startup line showing the mod and Minecraft versions. You can also run the client command:

~~~text
/inputbooster
~~~

It reports the mod version, Minecraft version, Sodium integration status and overlay state.

If the mod does not load, check Java, Fabric Loader, Fabric API and the exact jar name before changing settings.
