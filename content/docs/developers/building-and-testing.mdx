<Lead>
The repository currently contains seven independent Fabric Gradle targets. Gradle itself must run on Java 25; the 1.21.x projects also use a Java 21 compilation toolchain.
</Lead>

## Project matrix

| Project directory | Minecraft | Mod version | Java toolchain |
| --- | --- | --- | --- |
| <code>fabric/</code> | 26.2 and 26.3 | 4.1.2 | 25 |
| <code>fabric-26.1/</code> | 26.1 | 4.1.2 | 25 |
| <code>fabric-26.1.2/</code> | 26.1.2 | 4.1.2 | 25 |
| <code>fabric-1.21.1/</code> | 1.21.1 | 3.1.5 | 21 |
| <code>fabric-1.21.4/</code> | 1.21.4 | 3.1.5 | 21 |
| <code>fabric-1.21.11/</code> | 1.21.11 | 3.1.5 | 21 |

The <code>fabric/</code> project builds both 26.2 and 26.3 through its Minecraft/API Gradle properties. The release workflow also builds the other five project directories, for seven artifacts total.

## Java runtime versus toolchain

Use a Java 25 runtime to launch Gradle for every project. Fabric Loom 1.18.2 requires at least JVM 25 to run. The 1.21.x source is compiled with a Java 21 toolchain, which the CI workflow installs separately and exposes to Gradle.

Do not launch Gradle itself with Java 21. A previous CI attempt did so and failed before project configuration because Loom requires JVM 25; the workflow was corrected to keep the Gradle runtime on Java 25 while selecting Java 21 for compilation.

## Build commands

From the repository root, run the command for the target project.

### Minecraft 26.3

~~~bash
cd fabric
./gradlew clean test build --no-daemon
~~~

### Minecraft 26.2

~~~bash
cd fabric
./gradlew clean test build --no-daemon \
  -Pminecraft_version=26.2 \
  "-Pminecraft_version_range=>=26.2 <26.3" \
  -Pfabric_version=0.161.0+26.2
~~~

### Minecraft 26.1 and 26.1.2

~~~bash
cd fabric-26.1
./gradlew clean test build --no-daemon

cd ../fabric-26.1.2
./gradlew clean test build --no-daemon
~~~

### Minecraft 1.21.x

~~~bash
cd fabric-1.21.1
./gradlew clean test build --no-daemon

cd ../fabric-1.21.4
./gradlew clean test build --no-daemon

cd ../fabric-1.21.11
./gradlew clean test build --no-daemon
~~~

The 1.21.x Gradle builds still run on Java 25; Gradle selects Java 21 for the Java compilation toolchain. On Windows, use <code>gradlew.bat</code>.

## Tests and artifacts

Each matrix target runs <code>clean test build</code>. The 26.2/26.3 project also contains the Minecraft-version signature checks for its mixins and the metadata range checks. The release workflow validates the expected artifacts before publishing.

Build outputs are written under each project's <code>build/libs</code> directory. The release job attaches the seven version-specific jars to the release tag <code>v4.1.2-beta3</code>.

## Current GitHub Actions workflow

Only <code>.github/workflows/gradle.yml</code> is present in the current source branch. It runs the seven-project build/test matrix and publishes the release artifacts. The earlier standalone <code>test.yml</code> and <code>client-smoke.yml</code> workflows are no longer present.

<Callout variant="warning" title="CI does not currently launch Minecraft">
The current workflow builds and runs tests but has no headless client startup job. A successful CI build therefore does not prove that the game launches on every graphics stack. The latest recorded client-smoke run failed in several matrix combinations; see [limitations](/docs/reference/limitations).
</Callout>
